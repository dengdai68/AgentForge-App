# Electron

客户端是唯一产品入口。子服务要求父进程 IPC、bootstrap 信息和随机 loopback 端口；父进程断开即退出，页面始终使用客户端样式。

任务与目录共用紧凑顶栏，团队/工作流搜索和任务归档/新建均在搜索行；目录操作区上移。用户提供的蓝紫 A PNG 为唯一图标源，保留原始字节并生成 macOS ICNS；侧栏、Dock、安装包与托盘 alpha 轮廓同源，不新增宿主桥。控制台显示完整脱敏提示词、原生会话 ID、正文/思考/工具与异常，不显示工具审计详情。人类协作元信息在气泡外右对齐，正文内边距独立，已知 @成员以黑色粗体展示。

团队/工作流使用共享目录工具栏，不再在创建操作区下添加列表顶边框；保留条目间分隔，不修改域命令或宿主接口。

沟通附件、未读与右侧半屏控制台复用认证 HTTP 和共享 renderer，compact.css 仅调整紧凑间距；不新增通用宿主桥。测试使用隔离 HOME、实例与下载目录；真实模型专项只在源码隔离客户端调用已授权 Claude Code，安装包使用受控 CLI。

runtime-paths.mjs 复用 server/data-home.mjs 的纯路径函数，将默认任务根统一为 ~/agentforge，不跟随 desktop/web 应用数据目录。已保存值和已有任务路径不搬动。测试可传入 fixture home 隔离目录。CLI 源码/安装版统一只发现客户端，无 Web 目标；CLI 安装入口仅宿主界面显示。

员工、插件/MCP 目录共享同行搜索/操作与卡片；compact.css 只调整桌面密度。市场详情删除使用共享应用确认框与认证 HTTP，失败就地提示，不新增原生弹框或宿主接口。

| 文件 | 职责 |
| --- | --- |
| `main.mjs` | 窗口、菜单栏、自有子服务、启动与退出 |
| `policy.mjs`、`preload.cjs` | 精确来源校验与封闭宿主方法 |
| `runtime-paths.mjs` | 独立实例路径和后台环境 |
| `login-shell-env.mjs` | 一次性登录 shell 环境捕获 |
| `preferences.mjs` | 关闭行为偏好 |
| `app-dialog.*`、`cli-confirmation.*` | 宿主确认窗口 |
| `cli-installation.mjs` | 用户级命令安装 |
| `compact.css` | 桌面样式与响应式配置弹窗 |

运行与边界见 [Electron 文档](../../docs/18-electron-client.md)。共享业务 UI 在 `web/`，此目录不拥有 Store 或 Provider 状态。

`runtime-paths.mjs` 同时定义 Chromium userData/sessionData、日志和崩溃目录，全部默认位于 ~/.agentforge 的实例目录；main 在 ready 前设置。任务工作目录不是应用数据根。

员工和插件/MCP 市场使用响应式紧凑卡片，保留既有命令与信息；创建员工也可停用，插件与 MCP 搜索器分行。插件详情用概要和组件标签页，不扩展宿主接口。

任务空间沿用共享的当前文件/CHANGE 文件树和返回列表入口；已移除交付版本页面，仅清理对应桌面样式，不改变历史文件或后台接口。

当前文件下载复用认证 HTTP 和浏览器下载，不新增宿主文件/进程桥；工具栏为下载/刷新保留右对齐紧凑组合，覆盖窄窗口。

提示词随普通时间线分页；运行中成员、协作类型和沟通发送者复用共享语义色，桌面保留紧凑中性正文。打包 E2E 检查活动/终态颜色、超过 50 条的分页及沟通颜色。
