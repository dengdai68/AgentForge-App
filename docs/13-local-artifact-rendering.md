# 工作目录与 CHANGE

沟通附件不是 Task Artifact：原文件保存在 `communications/<会话ID>/attachments/<附件ID>/<原文件名>`，单文件最多 20 MiB，同名文件不覆盖。Store 登记元数据并冻结到消息；下载检查本会话引用、路径、链接及 SHA-256/字节，以 attachment/octet-stream 返回原字节。损坏/缺失明确报错，不回退任意本机文件；员工得到可见消息中的实际位置后自行读取，不自动注入文件正文。

## 文件视图

任务空间的「工作目录」仅包含当前文件与 CHANGE，不再提供交付版本页面。移除的是界面与相关入口，不删除 Trace 绑定的不可变 Artifact 历史、文件或 API/CLI 查询能力。验收入口引导到当前工作目录；缺陷仍可查看来源控制台，不把当前文件冒充历史快照。

文件树展示整个任务工作目录中的普通文件和目录，包括根文件、工作流自定义目录、媒体和绑定的 `repos/`；`docs/` 没有特殊地位。Git 忽略文件也可浏览，但 CHANGE 仍遵守 Git 的忽略规则，不自动暂存、修改忽略规则或提交。内部 `.git`、`.agentforge`、已废弃的展示清单和已知凭据文件不公开，符号链接不跟随。目录按需展开，每页200项，可继续加载，不再递归截断1000项。文件内容按选择读取：Markdown 使用本地 marked + DOMPurify；代码按语言高亮；PNG/JPEG/GIF/WebP 通过受限 raw 接口展示，SVG 作为源码。大文件/二进制仍列出并可完整流式下载，不强行生成文本预览。

当前文件与 CHANGE 的根目录使用同一紧凑样式，不为折叠根保留分组空白。当前文件工具栏在刷新旁提供下载：未选择文件时禁用；下载选中文件的完整当前字节，不下载预览转换文本或历史快照。`GET /api/runs/:runId/working-directory/content?download=1&path=...` 走同一认证与工作根/敏感文件/符号链接检查，以 attachment 和 octet-stream 流式返回；不受预览截断上限影响。客户端保存前检查响应错误，失败保留当前任务页面并提示，不声称保存成功。文件仍可被外部进程修改，不提供冻结快照保证。

## 工作区协议

不再生成或读取 `.agentforge-workspace.json` 作为展示白名单；已有文件不修改、不迁移。目录位置由工作流的 `artifactPaths` / 交付要求约定，可用任意规范的工作目录相对路径，未指定时不自动填充 docs。`repos/` 保留研发员工绑定仓库的检出和初始提交关联，不限制其他业务目录。任务详情展示相对工作路径，复制得到绝对路径。

`GET .../working-directory?path=<目录相对路径>&offset=N` 返回该层 `entries`、`path` 与 `nextOffset`（末页为null），根path缺省为空，offset为非负整数。当前文件和CHANGE使用同一真实路径层级，不依赖此目录分页才能显示已删除文件。刷新重新读取已展开目录，读取失败允许重试，分页和目录选择不串入其他Run。

新工作根初始化 Git，`repos/` 下克隆仓库注册为 gitlink，不暂存员工文件或改变子仓库索引。初始化失败只写诊断。

## 差异

CHANGE 不在各目录下重复显示「没有更改」；有变更时只展示目录树与差异。仅全部仓库成功读取、已初始化且都无变更时，在树外显示一次整体空态。读取失败或未初始化保留真实提示，不冒充无变更。

子仓库使用根仓库首次提交中保存的 gitlink 作为任务初始版本，对比当前文件，覆盖已提交与未提交改动。没有初始记录时明确标注 HEAD 回退；缺失对象报读取错误。由平台初始化的工作根使用自己的初始化提交作为任务初始版本，覆盖本任务已提交、未提交与未跟踪文件；已有外部根仓库没有此初始化记录时回退HEAD，不能把外部项目全部历史当作任务更改。不因为文件在docs外或体积大而隐藏。冻结交付快照继续受单文件20MiB和文件数上限约束，不把当前可下载文件冒充不可变快照；执行文件记录覆盖所有业务路径，失败如实写诊断。

CHANGE 与当前文件使用同一树渲染器，按真实相对路径层级展示，不额外套「工作目录/仓库」标题；排序、图标、层级与折叠操作一致，CHANGE 另有新增/修改/删除标记。两种视图各自保留选择、折叠与滚动状态。仓库比较基线显示在选中文件的预览头部，不作为额外目录分组。支持行内/左右、仅差异/完整文件，完整上下文通过 `full=1` 按需读取，仍有大文件和二进制提示。

## 读取边界

Artifact 内容使用冻结 SHA-256 与字节信息验证；错误不冒充为空文件。路径与符号链接读取限制保护预览和快照，不构成员工文件操作沙箱，也不参与业务结果验收。文件内容不进入历史全文索引。
