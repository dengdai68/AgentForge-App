# 产品与协作

AgentForge 在本机组织由 Claude Code/Codex 驱动的数字团队。

## 核心对象

- 数字员工：名称、简介、提示词、能力、Runtime、Skill/MCP；研发员工可绑定 Git 仓库。
- 团队：项目经理、业务员工和本机人类。通过搜索选择员工，已选成员单独展示。
- 工作流：节点、人员需求、交付说明和预期交接关系。
- 任务：目标、团队与冻结工作流；一次执行对应一个 Run。

## 执行方式

人类提交目标，经理选择员工并推进交接。员工可以咨询其他成员、向人类提问、报告问题和提交普通文字结论。平台负责消息、派发、运行与记录；业务判断由专业员工完成，经理依据协作情况推进，人类显式确认完成。

每位员工独立会话。同一 Run 的后续调用恢复原生会话；不同员工可以共享同一工作目录。

## 任务空间

- 协作记录：交接、咨询、问题与人类回复，正文按 Markdown 展示，先渲染最近 30 条。
- 工作目录：当前文件与 CHANGE 复用紧凑目录树，分别展示最新文件与变化；文件和差异按选择读取，当前文件支持下载完整原始字节，不再展示交付版本。历史 Artifact 仍保留，不删除审计事实。
- 控制台：点击员工才加载历史，每页 50 条；可见工具行收起时也展示 Bash 命令和 Read/Write 文件路径，正文与提示词展开且接近可视区域时读取。成功 Read 展开显示 Done，失败保留错误，Write 展示已记录写入文本而非 JSON 信封；无法解析或未保存时如实说明。
- 任务详情：团队、工作流链接、相对工作目录与任务描述；复制目录得到绝对路径。
- 任务标题左侧提供返回列表按钮，返回保留搜索条件。控制台不重复回显协作消息正文，协作全文仍在协作记录。

## 本机使用

桌面首次启动设置管理员。Runtime 使用已安装并登录的本机 CLI；模型可从目录选择或手工输入，思考等级按 Provider 能力配置。登录态持久保存，默认不因时间自动过期，退出或重置后撤销。

员工以本机用户权限运行，工作目录是启动位置。平台不提供 Agent 沙箱或多租户隔离。客户端与 CLI 的账户与数据边界见认证和客户端文档。
