# 界面约定

工作目录按完整真实路径组织，当前文件按需展开与分页继续加载，CHANGE复用同一层级/图标并保留删除项；目录加载/错误/重试只属于该目录，不因全树重建切走文件选择。大文件仍提供元数据与下载。

插件自动更新控制集中在设置的「插件更新」分类，开关、周期和保存/立即检查采用现有表单样式；市场不混入运行设置。后台状态刷新不覆盖未保存输入。沟通初次无选择时显示最后更新会话；任务控制台初次无选择时显示最近开始执行的成员，之后尊重显式选择，不因刷新跳转。

人类协作记录靠右，时间、类型、收发人及状态置于正文气泡外，类型和收发人右对齐；正文气泡上下 10px、左右 12px 内边距，不强设最小宽度，首尾段落不额外留白。已知成员的 @提及使用与成员名称一致的深色粗体，不改变路由或 Markdown 代码/链接内容。员工消息仍靠左。

协作流只按真实消息时间展示经理结论、交接与后续提问，不在列表末尾附加固定的验收说明副本。确认完成仍是顶部独立的人类操作；不展示「停止答疑」，未归档任务保留输入，归档后只读。删除被进行中的答疑阻塞时提示等待答复，不引导不存在的界面入口。

任务和沟通控制台不平铺无正文的开始/保存、普通会话连接、空 Provider 进度或诊断占位通知。保留正文、思考、工具、提示词，以及失败、重试、取消、会话重建和恢复；未知消息不默认隐藏。完整原始事件与详细诊断仍在原有审计/日志中，不改变执行状态、分页或 CLI/API。

团队、工作流保留语义页标题，与员工一样提供同行搜索/创建按钮；按名称和说明过滤后分页，输入回第一页。目录工具栏为紧凑 44px、上移操作区；客户端使用留白连接列表，不添加列表顶边框。任务中心使用同样的顶部导航，搜索名字段有界收窄，搜索/重置/归档历史/新建任务按此顺序同排，窄屏自然换行。筛选草稿和按钮焦点不被刷新销毁。

任务和沟通控制台共用同一 renderer/hydrator：本次提示词完整展开已脱敏系统指令和本轮输入，下面显示对应已确认 Claude Code/Codex 原生会话 ID，未记录时如实标注。移除长快照说明和工具审计详情；截断/缺失仍明确提示。同一工具调用的重复阶段和相同公开输入不重复展示，不合并不同 ID 的真实调用。空 tool_progress 通知隐藏。侧栏、Dock 和安装包共用用户提供的 A 图标。

沟通控制台顶部工具栏只放「最新」「刷新」，不重复员工姓名；单个成员不渲染选择标签，群聊的成员切换和历史分页入口放在工具栏下方，不占顶部工具栏。保留成员查询、错误显示和阅读状态，不变更执行协议。

插件/MCP 卡片和详情复用员工头像形状与五色 palette，按稳定安装 ID 配色。沟通输入仅保留可访问名称，不显示冗余「消息」标签；附件添加、待发移除、下载支持键盘。列表只标记真实 unreadCount，移除 pending 点。控制台文字入口有 aria-expanded，是聊天标题栏右上角的唯一开关，右侧展开与聊天各占一半；分隔线贯穿标题栏顶部和内容，右侧直接展示成员选择和日志，不重复标题或收起按钮。沿用任务详情侧栏的展开/收起交互，开关不销毁输入框。窄屏仍各半，缩短会话列表并约束整体高度，使发送按钮可见；面板内部滚动、文件名省略但不撑宽。工具/思考/正文复用任务控制台格式化。

员工插件/MCP 下拉不长期遮挡下方字段：鼠标移出选择区或焦点离开搜索/候选区时收起，点击表单其他区域也收起。鼠标从输入移动到候选项（含间隙）不能提前消失；复点输入重开，方向键与 Enter 选择，Escape 收起并保留编辑框，隐藏候选不遗留不可见焦点。收起不清空查询或更改员工选择。

员工、插件、MCP 卡片为名称和三行简介预留固定高度，Runtime、状态与操作区对齐，不因简介空白或过长改变关键位置；卡片省略不修改原始字段，完整内容在详情/编辑读取。插件详情只让正文滚动（含概览与全部组件），组件标签吸顶，标题和底部操作固定可见；不可通过裁剪隐藏长列表，也不以限制 Skill 数量代替滚动。

员工、插件/MCP 目录使用共享卡片和 `directory-toolbar`：左侧搜索、右侧创建/手动安装始终同一行，窄屏输入可收缩；不额外显示「搜索已安装…」标签，保留 aria-label。插件/MCP 卡片保留现有摘要与详情操作，详情页的删除与关闭并排，危险操作使用应用内确认与就地引用错误，不用系统弹框。

插件/MCP 未安装、搜索无匹配、加载中和读取失败均使用卡片网格之外的独立整行状态区，不按一张卡片的宽度展示，不把读取失败误报为空市场。

renderer 与 Electron 共享真实语义和命令。优先使用现有颜色、字体、间距、焦点和按钮样式；桌面覆盖位于 `apps/electron/compact.css`。

角色侧栏入口使用继承当前文字颜色的 SVG 人物名牌图标，宽窄窗口不依赖字体字形。角色与其他可选入口一同登记在 `preferences.mjs` 的 NAVIGATION 中，外观设置可隐藏并持久保存，恢复默认会重新显示；BUILD 内全部入口隐藏时分组也隐藏。这些都是客户端展示偏好，不改变角色配置或 CLI 协议。

- 列表提供搜索、分页和明确空态；不一次平铺大型员工目录。
- 团队编辑按名称或能力搜索员工，最多显示 20 个候选；已选员工单独列出并可移除。
- 工作流详情的节点导航只显示标题，完整说明在内容区展示；编辑节点可折叠。
- 长配置弹窗宽高随视口变化，正文内部滚动，底部操作可见；小窗口切换单列。
- Markdown 通过本地 marked + DOMPurify 渲染，加载失败显示转义文本。
- Shell 保留原始换行和终端主题；Edit 差异逐行展示，不插入额外空行。
- 工作目录只有「当前文件」和「CHANGE」：两者复用目录树、目录优先排序、图标、缩进与折叠逻辑，分别展示当前文件与发生变化的文件；CHANGE 的布局与范围图标组和刷新右对齐，支持行内/左右、仅差异/完整文件。
- 工作目录使用 vscode-icons 子集，主题仅作用于工作目录树和选中文件预览。
- 当前文件与 CHANGE 的根目录按内容紧凑排列，折叠后不留分组空白。当前文件的下载与刷新相邻，未选文件禁用下载；读取失败就地提示，不以导航错误页替代任务页面。
- CHANGE 不在各目录下显示「没有更改」；仅全部成功读取且无变化时展示一次整体空态，读取失败、未初始化与加载中不得误报无变化。
- 控制台、协作记录使用可用窗口宽度；日志和重内容按需加载。
- 提示词按 Trace 开始时间排列，每个调用只出现一次；分页尚未覆盖其时间时不提前固定展示，加载旧页后按时间合并，正文仍按需读取。
- 执行中成员以蓝色底色、边线及文字区分；终态恢复中性。协作使用蓝色（人类）、紫色（经理决策/咨询）、青绿（交接/答复），待答用琥珀色。状态文字保留，颜色不代表业务通过。
- 私聊/群聊沿用上述色彩，人类蓝色、员工按稳定身份使用青绿/紫色；强调姓名、已有加粗/标题和引用，正文保持中性色。桌面保留紧凑记录，使用紧凑对话呈现。
- 协作记录和沟通按实际发送者布局：人类消息靠右，员工消息靠左（包括员工发给人类的消息）；不是按“涉及人类”筛选标记判断。人类记录宽度有上限，正文仍左对齐以便阅读 Markdown/代码；保持时间顺序、回复入口和分页语义。
- 控制台不再次回显 `message.sent` 协作正文；正文在协作记录保留，Runtime 输出和失败等执行事实仍显示。任务标题左侧提供有可访问名称的返回列表图标按钮，和标题保留明确间距，返回时保留任务搜索条件。
- 控制台可见工具行无需展开即可显示 Bash 命令、Read/Write 文件路径；这三类连续调用的分组默认展开行摘要，用户仍可收起。摘要仅来自已脱敏且通过完整性校验的执行内容。成功 Read 展开显示 Done，失败保留错误；Write 展开直接呈现写入文本及脱敏/截断提示，无法解析时如实回退。
- 图标按钮具备可访问名称，选中态可辨识，键盘可以完成搜索、选择和关闭。

退出入口位于设置 → 常规底部。任务详情默认关闭，任务描述显示前 100 字并可展开。

角色的未创建及搜索无结果状态复用 MCP/插件的 market-directory-empty 整行提示，位于卡片网格外；不在空态重复创建按钮，入口保留在工具栏。

角色、MCP 和插件目录空态共用 market-directory-empty，使用主题 surface-soft 浅色背景及 6px 圆角，宽窄布局一致。
